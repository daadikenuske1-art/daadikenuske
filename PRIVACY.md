# Privacy Policy — DaadiKeNuske

This application ("DaadiKeNuske") is an automated content pipeline that generates
and uploads Hindi-language home-remedy videos to the DaadiKeNuske YouTube channel.

## What this app accesses

This app uses the YouTube Data API v3, solely to upload video files and their
titles, descriptions, and tags to a single YouTube channel that is owned and
operated by the same account that authorized this application. No data
belonging to any other user or channel is accessed, read, or shared.

## Data storage

No personal data from viewers or third parties is collected, stored, or
processed by this application. The only credentials stored are the OAuth
tokens needed to upload content to the operator's own YouTube channel, and
these are kept as encrypted secrets in a private automation environment.
